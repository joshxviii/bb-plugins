To use this plugin, first open the Model Project that you would like to render another model on. For Bedrock Models, simply add a locator to the model and select it from the menu. For Modded Entity Models, create a group named: "locator:[name]". After that you can select the locator and any other open Model Project file. The selected Model will render on a selected Locator or Locator Group.

This plugin was made for Cobblemon models, but should work with other bedrock entity models and modded entity models.
